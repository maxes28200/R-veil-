# Réveil V2

Mini application web mobile pour calculer automatiquement l'heure de réveil.

- Autocomplétion d'adresses françaises via l'API Géoplateforme / BAN-IGN.
- Calcul automatique des durées voiture via OSRM.
- Temps de préparation libre.
- Marge de sécurité fixe de 15 minutes.
- Plusieurs trajets successifs.
- Sauvegarde locale des derniers réglages.

Ouvrir `index.html` dans un navigateur connecté à Internet.


## V3
Ajout d’un champ « Temps sur place » pour chaque trajet. Ce temps est inclus automatiquement dans le calcul de l’heure de réveil et dans la timeline.
